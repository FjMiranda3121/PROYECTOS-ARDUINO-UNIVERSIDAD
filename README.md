Repositorio con los proyectos, scripts de código e informes de prácticas de laboratorio desarrollados durante la carrera universitaria.

* **Componentes:** LEDs, Servomotores, Potenciómetros, Sensórica varia
* **Lenguaje:** C++ / Wiring
